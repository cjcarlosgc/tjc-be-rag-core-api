Ningún evento que Integration emite hoy queda rechazado por el esquema. Salvo D-A (abajo).

Correctas, salvo la matización CR-1 (hay una cuarta dirección en calendario).
- **D-A (action sin tope en Integration):** confirmado, `normalizer.ts:26-27` solo exige string. Core rechaza `>100` (`:72`) y el esquema también. No es regresión: Core ya rechazaba. Tratarlo como informativo para Integration (A-2) es correcto.
- **D-D (vacíos):** igual que (iii); el esquema sin `minLength` coincide con Core (A-1 correcto).
- **D-H (`accepted: const true`):** `github-webhooks.service.ts` solo construye `accepted: true` (`:56-60`, `:89`, `:117`) y no existe rama `accepted:false`; Integration también exige `body.accepted === true` (`github-webhook-core-client.ts`, `isAcceptedResponse`) y su tipo es `accepted: true`.
