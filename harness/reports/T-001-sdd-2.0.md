## GitHub architecture migration

```text
OLD: GitHub login -> account repositories -> repository selector -> branch selector -> manual import
NEW: GitHub App installation -> Project↔Repository binding -> Pull Request -> webhook -> automatic AnalysisRun -> GitHub Check -> human-in-the-loop
```

## Trigger policy

```text
No relevant PR -> no automatic analysis
Relevant PR opened/ready -> analysis
New commits pushed to active PR -> pull_request:synchronize -> new HEAD -> previous Run obsolete -> new Run
```

## Stack strategy

```text
TypeScript/Jest/Vitest -> compatibility maintained
PHP/Laravel/PHPUnit -> active new-development focus
```

## Human-in-the-loop

```text
missing functional knowledge -> ACTION_REQUIRED -> GitHub Check -> Console Focus Mode -> answer -> FunctionalKnowledge -> continuation Job -> same Run if HEAD unchanged
```

## Test publication

```text
validated generated test -> human review -> HEAD freshness check -> companion branch -> companion PR to feature branch -> human merge -> original PR synchronize -> revalidation
```
