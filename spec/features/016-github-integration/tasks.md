La matriz de cierre cubre: (a) caminos Core→Integration del pipeline y webhook normalizado; (b) rutas Core de discovery/verify/branches preservadas; (c) callback GH→Core con sesión/identidad/acciones, sin retorno Core→GH durante la comprobación; (d) evidencia de binding firmada y scoped; (e) Console directo solo para capacidades GitHub; (f) Storage y ZIP interno sin cambio; (g) redirecciones rechazadas y HTTPS obligatorio fuera de loopback.

La promoción de `WI-CORE-003` queda protegida por `WI-CORE-009`; el estado cruzado GH/Core se confirma con evidencia manual, no mediante una consulta automática entre repositorios. El parser JSON privado de blobs fue comprobado en GH: límite específico de ruta `136mb`, previo al parser JSON general de `100kb`; Base64 para el máximo de `100,000,000` bytes ocupa hasta `133,333,336` caracteres más el envoltorio JSON. Esto no mueve la propiedad ni persistencia de archivos fuera de Core/Storage.

Las operaciones GitHub pertenecen a Integration; este WI conserva autorización/persistencia de dominio Core y consume el callback sin consultar nuevamente GitHub. Las rutas Core previas siguen disponibles como compatibilidad. Los WIs quedan abiertos en revisión técnica con el gate de aprobación personal pendiente; no se despliega ni cambia el cutover sin autorización expresa.
